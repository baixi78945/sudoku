# 数独 · Sudoku

一个零依赖、单文件的网页数独游戏。全部代码（HTML + CSS + JS）都在 `index.html` 里，双击即玩，不需要联网、不需要构建。

## 特性

- **保证唯一解**：随机生成终盘后逐格挖空，每次挖空都用回溯求解器校验解的唯一性
- **四档难度**：简单 / 中等 / 困难 / 专家（45 / 34 / 29 / 24 个提示数）
- **笔记模式**：格内小字候选数，填对后自动清掉同行、同列、同宫的该候选
- **智能高亮**：选中格高亮所在行/列/宫，并高亮盘面上所有相同数字
- **冲突检测**：同行、同列、同宫重复的数字立即标红
- **计时 / 错误计数 / 提示 / 撤销**：撤销支持多步回退
- **响应式**：桌面双栏，手机单栏紧凑布局

## 玩法

| 操作 | 说明 |
| --- | --- |
| 鼠标点击 | 选中格子 |
| `1` – `9` | 填入数字（再按同一数字可取消） |
| `Del` / `Backspace` / `0` | 擦除 |
| 方向键 | 移动选中格 |
| `N` | 切换笔记模式 |
| `H` | 提示（为当前格或随机空格填入正确答案） |
| `U` / `Ctrl+Z` | 撤销 |

## 运行

直接用浏览器打开 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 实现要点

- 求解器用位掩码标记行/列/宫的已用数字，并做 MRV（最少候选优先）搜索
- 生成器先随机回溯生成一个终盘，再按 180° 对称挖空；每次挖空后求解器给出 2 个解即回填
- 单局生成耗时通常在 10 ms 以内
